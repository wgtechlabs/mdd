# D Theme changelog

## 0.3.0 — D26 (unreleased)

Move the full search control into the documentation sidebar and show a compact
search control beside the sidebar toggle when navigation is collapsed. Keep the
site brand, project links, and CTA in the top bar. Align the sidebar to the left
edge and slide its navigation fully offscreen when collapsed, while leaving its
search and toggle controls available. At mobile and tablet widths, use a sticky
bar with documentation-menu and page-outline disclosures. Keep the active page
outline synchronized while scrolling. Preserve D Theme's color palette and the
existing disclosure and sidebar preference behavior.

## 0.2.0 — D26 (unreleased)

Add distinct, labeled treatments for GitHub-style Note, Tip, Important, Warning,
and Caution alerts with decorative vector icons and light/dark color tokens.
Add the shared reader's search control and compact search dialog with page/heading
icons, context breadcrumbs, selected rows, and keyboard hints.
Highlight matching keywords with the existing accent and canvas colors in both
light and dark search results.
Group social links and MDD credit in the footer. Preserve native keyboard focus,
44px controls, reduced-motion behavior, and forced-color readability.

This minor update keeps the D26 release name. The prior 0.1.0 entry describes
development history; no released theme snapshot has been archived.

## 0.1.0 — D26

Initial D Theme generation: blurple reader styling, light and dark modes,
responsive navigation, accessible focus states, article components, and a
footer with MDD and theme versions, expandable custom styling details, icon-only
light/dark control, grouped article actions, collapsible navigation, and credit
in the main footer. The desktop sidebar slides in and out with a stateful panel
icon, interruptible motion, and an immediate reduced-motion alternative.

D Theme is developed and distributed inside MDD. Its numeric version tracks
changes to the theme independently of the MDD package version. D26 is a release
name, not a separate theme or a calendar switch. Minor and patch updates keep
the release name; the next major theme release introduces D27.
